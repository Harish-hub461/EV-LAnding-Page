# VoltEdge — Electric Vehicle Landing Page

A responsive electric vehicle landing page built with HTML, CSS, and JavaScript, featuring a modern automotive design.

## Features
- Responsive landing page layout
- Interactive vehicle color selection
- Test-drive interest registration form
- Modern styling and hover effects
- Mobile-friendly design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Getting Started
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Explore the page and test its interactive features.

## Project Purpose
Created as a frontend development portfolio project to practice responsive web design, styling, and JavaScript interactions.
